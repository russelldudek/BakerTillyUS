Days 0-60

Establish the business system.

Build shared visibility into the work, the portfolio, the economics, and the decisions that will focus Baker Tilly Consulting's AI activation agenda.

Phase 1 | Days 0-30

Understand the work in practice

Learn how Consulting teams create value today and where AI can strengthen delivery.

Actions

  • Meet Consulting executives, practice leaders, delivery leaders, platform owners, data, security, legal, risk, learning, talent, and representative practitioners.
  • Observe priority workflows, reviews, handoffs, knowledge searches, exceptions, and client-delivery moments.
  • Reconcile the use-case inventory, active pilots, platform capabilities, dependencies, ownership, and adoption signals.
  • Define baseline measures for cycle time, quality, review burden, capacity, leverage, pricing, and reuse.

Outputs

  • Consulting AI system map
  • Portfolio fact base
  • Stakeholder and decision-rights map
  • Baseline scorecard
  • Priority workflow observations
Phase 2 | Days 31-60

Focus the activation portfolio

Convert broad opportunity into a small set of business-owned priorities.

Actions

  • Rank opportunities by client value, delivery impact, economic mechanism, feasibility, reuse, readiness, and adoption effort.
  • Write capability requests that define the outcome, workflow, users, data, integrations, human authority, evaluation, and operating owner.
  • Choose a balanced pilot set across knowledge work, client deliverables, onboarding, and bounded automation.
  • Align investment, sequencing, dependencies, and executive decision cadence.

Outputs

  • Prioritized activation portfolio
  • Value-conversion cases
  • Capability-request standard
  • Pilot charters
  • Executive decision calendar

Phase 3 | Days 61-90

Run measured, practice-owned pilots

Prove changed work and adoption, not tool activity.

Actions

  • Launch pilots with namd practice sponsors, workflow owners, technical counterparts, and clear review authority.
  • Pair each pilot with role-based learning, office hours, practice champions, manager coaching, and reusable context.
  • Measure output quality, cycle time, review burden, exceptions, repeat use, confidence, and support effort.
  • Capture technical dependencies, operating friction, reusable patterns, and client-value implications.

Outputs

  • Pilot evidence packs
  • Adoption scorecards
  • Champion network cadence
  • Reusable workflow patterns
  • Monthly value review
