Phase 1

Days 0-30

Read the system before changing the portfolio.

Listen at the work

Interview Consulting executives, practice leaders, implementation leads, platform owners, security, legal, risk, learning, talent, and representative practitioners.

Map the current portfolio

Reconcile use-case inventory, platform capabilities, active pilots, dependencies, ownership, adoption, evidence, and unresolved decisions.

Establish economic baselines

Define how priority practices currently create value: work mix, review burden, cycle time, leverage, utilization, capacity constraints, pricing, quality, and risk.

Outputs

  • Consulting AI system map
  • Portfolio truth table
  • Stakeholder and decision-rights map
  • Top operating tensions
  • Baseline scorecard definitions
  • Near-term decisions requiring leadership attention

Hypothesis to test: the primary constraint is no longer access to models; it is alignment around value, workflow, ownership, and evidence.

Phase 2

Days 31-75

Convert priority opportunities into business-owned pilots.

Choose a focused portfolio

Prioritize a small set of workflows across distinct practice conditions using value, feasibility, risk, reuse, readiness, and adoption burden.

Write capability requests

Define business outcome, workflow context, users, data, integrations, authority, constraints, evaluation, adoption expectations, costs, dependencies, and operating owner.

Launch role-based enablement

Pair pilots with embedded learning, office hours, practice champions, reusable prompts/context, manager coaching, and clear review expectations.

Outputs

  • Prioritized activation portfolio
  • Value-conversion cases
  • Technical capability request standard
  • Pilot charter and evaluation method
  • Champion network operating cadence
  • Executive decision review

Guardrail: no pilot proceeds without a named business owner, explicit human authority, adoption plan, and evidence standard.

Phase 3

Days 76-120

Turn pilot learning into a scalable consulting capability.

Decide with evidence

Scale, standardize, redesign, pause, or stop initiatives based on delivery impact, economics, trust, adoption, and reuse.

Package what compounds

Convert proven patterns into methods, accelerators, playbooks, knowledge assets, training modules, and reusable technical requirements.

Lock the operating cadence

Establish portfolio intake, quarterly priorities, monthly value reviews, pilot checkpoints, escalation paths, success-story capture, and executive reporting.

Outputs

  • Scale / redesign / stop decisions
  • Reusable Consulting AI methods
  • Role-based capability expectations
  • Portfolio scorecard
  • Investment and dependency roadmap
  • 12-month activation agenda

Success is visible when practices own changed workflows and measured outcomes—not when the central team owns more AI activity.
