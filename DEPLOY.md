# GitHub Pages Deployment

Repository: `russelldudek/BakerTillyUS`

Publish the site from the canonical `main` branch:

1. Open repository **Settings**.
2. Select **Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose `main` and `/ (root)`.
5. Save.

Expected candidate-vision URL:

https://russelldudek.github.io/BakerTillyUS/

After deployment, verify every HTML route, every PDF download, the mobile menu, the four scenario states, and reduced-motion behavior.
